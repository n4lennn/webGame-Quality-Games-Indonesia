# 🔮 Cek Khodam

Proyek web sederhana yang dibuat secara manual saat masih duduk di bangku SMK — tanpa framework, tanpa library, murni HTML, CSS, dan JavaScript vanilla.

## Tentang Proyek

Ini adalah salah satu proyek coding pertama saya. Dibuat untuk iseng mengikuti tren "cek khodam" yang sempat viral, sekaligus latihan menulis logika JavaScript dari nol. Semua kode ditulis tangan sendiri — tidak ada generator, tidak ada template.

## Cara Pakai

1. Buka file `kodam.html` di browser
2. Masukkan nama kamu di kolom input
3. Klik tombol **CEK KHODAM**
4. Tunggu beberapa detik... khodam kamu akan terungkap 👁️

## Teknologi

- HTML5
- CSS3 (tanpa framework)
- JavaScript Vanilla (tanpa library)
